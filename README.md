# 100 Days Speaking Scripts

React + TypeScript + Vite. Do NOT open index.html with Live Server.

## Run locally
    npm install
    npm run dev        # open the printed http://localhost:5173 link

## Preview the production build
    npm run build
    npm run preview

## Deploy on GitHub Pages
1. Push to the `main` branch (include the `.github` folder).
2. Repo Settings, Pages, Source: **GitHub Actions**.
3. Wait for the Actions run to finish, then open the page link.
